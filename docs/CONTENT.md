# 캐릭터와 스토리 교체

## 대사

`src/content/chapters.ts` 의 `CHAPTERS` 배열만 고치면 됩니다.

```ts
{
  id: "sprout",                    // 저장용 식별자 — 바꾸면 그 챕터를 다시 봅니다
  title: "1장 · 첫 그루터기",
  character: "./story/sprout.svg", // public/ 아래 경로
  characterName: "새싹",
  lines: ["첫 번째 대사", "두 번째 대사"],
}
```

`lines` 에 넣은 만큼 한 줄씩 넘어갑니다. 개수 제한 없습니다.

## 이미지

`public/story/` 에 **같은 파일 이름으로 덮어쓰면** 코드는 건드릴 필요가 없습니다.

지금 들어있는 SVG 4개는 **자리를 잡아둔 임시 그림**입니다. 조건은 이렇습니다.

- 형식: svg · png · webp · jpg
- 비율: 세로가 조금 긴 형태 (기준 128×160)
- 화면에서 148px 정도로 표시됩니다
- 배경은 투명하게 두면 카드 위에 자연스럽게 얹힙니다

다른 이름을 쓰고 싶으면 `chapters.ts` 의 `character` 경로도 같이 바꾸세요.

## 챕터 추가

`CHAPTERS` 에 항목을 추가하면 **스테이지 수도 같이 늘어납니다** (챕터당 5스테이지). 난이도 곡선은 전체 스테이지 수에 맞춰 자동으로 다시 펴집니다.

챕터당 스테이지 수를 바꾸려면 같은 파일의 `STAGES_PER_CHAPTER` 를 고칩니다.

## 스토리가 나오는 시점

챕터의 **마지막 스테이지를 별 1개 이상으로 통과**했을 때 한 번 재생됩니다. 이미 본 챕터는 `seenChapters` 에 기록되어 다시 나오지 않습니다.

테스트 중에 다시 보려면 브라우저 콘솔에서:

```js
localStorage.removeItem("makezero.progress.v1");
```
